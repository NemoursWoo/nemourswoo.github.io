This is my first blog post. I've just set up this personal website using Jekyll — built from scratch with a custom theme, no frameworks, no JavaScript, just clean HTML and CSS.

## Why build from scratch?

I wanted a site that:

- Loads instantly (no JS, no external fonts beyond system defaults)
- Is easy to maintain (just Markdown files)
- Gives me full control over every line of code
